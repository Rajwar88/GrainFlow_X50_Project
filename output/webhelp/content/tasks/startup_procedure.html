Startup Procedure

Follow these steps to safely start the GrainFlow X50.

Pre-Start Checklist

Complete the following checks before starting the machine:

Check Action Required
Visual Inspection Inspect all guards, covers, and safety devices for damage or missing parts
Power Supply Verify main power supply is connected and within voltage specification (400V ± 10%)
Cleaning Ensure all interior chambers are free from debris from the previous shift
Bearing Lubrication Check bearing lubrication status. Top up if necessary
Emergency Stop Verify emergency stop button is released (twist to reset)
  1. Locate the main power switch on the control panel.

    Refer to the control panel diagram in the appendix.

  2. Turn the switch to the ON position.

    The HMI (Human Machine Interface) will display the startup screen.

  3. Wait 60 seconds for the system self-diagnostic to complete.

    The system checks sensor responses, motor RPM, and fault codes.

  4. Enter the desired throughput rate on the HMI touchscreen.

    Default rate is 50 tonnes per hour. Range is 20-80 TPH.

  5. Press the Start button on the HMI screen to begin operation.

    The system starts main motor, conveyor belt, and cleaning process.
