Adjusting Airflow Settings

Optimize grain cleaning efficiency by adjusting airflow.

Understanding Airflow

The GrainFlow X50 uses a precision airflow system to separate lighter impurities from the grain.

Low Airflow (10-20%)
Used for delicate grains to prevent damage (e.g., rice, millet)
Medium Airflow (40-60%)
Standard setting for wheat, barley, and oats
High Airflow (80-100%)
Used for heavy grains or high moisture content (e.g., maize, soybeans)
  1. Access the Settings menu on the HMI.
  2. Select Airflow Configuration.
  3. Use the slider or numeric input to set desired airflow percentage.

    Current airflow is displayed in real-time.

  4. Press Apply to save changes.

    The new airflow setting will take effect immediately.

Wheat-Specific Settings

For wheat, we recommend an airflow setting between 50-65% to achieve optimum cleaning efficiency.

Maize-Specific Settings

Maize requires higher airflow. Start at 75% and adjust based on moisture content.

Rice-Specific Settings

Rice is delicate and requires lower airflow. Recommended setting is 20-30%.
