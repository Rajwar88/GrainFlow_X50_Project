Filter Replacement

Replacing filters at the correct interval maintains airflow efficiency.

When to Replace Filters

  • Every 500 operating hours
  • When airflow drops below 80% of optimal
  • Visible damage to filter material
  1. Shut down the machine and disconnect power.

    Never change filters while the machine is running or connected to power.

  2. Open the main filter access panel.
  3. Remove the old filter element.

    Dispose of the old filter according to local environmental regulations.

  4. Clean the filter housing using a vacuum.
  5. Install the new filter element, ensuring proper alignment.
  6. Close the access panel securely.
  7. Restart the machine and verify normal airflow.
